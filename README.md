# Interactive Birthday Website 🎂

A tap-through birthday experience built with vanilla HTML, CSS and JS. Five story slides, ambient particles, a blow-out-the-candles interaction and a confetti finale.

## How to use
#for laptop users
   1. click on the html css file and download it
   2. extract the downloaded zip files
   3. open the folder in vs code
   4. right click and open with live server
      
  #for mobile users
  1.copy the link
 2. open replit
 3. import the repo
4. project will open and run
## Features

- 5-slide tap-through story (intro, compliment, reasons list, wish, finale)
- Real candle-blow interaction, tap to snuff each candle out
- Confetti burst on the final slide
- Ambient floating particles and balloons
- Progress dots that track slide position
- Replay button to loop the experience
- Keyboard support (arrow keys / space)
- Fully responsive, works on mobile
- No dependencies, single file



## Customize it

- Edit the text inside each `<section class="slide">` block to personalize the message
- Colors are set as CSS variables at the top of the `<style>` tag under `:root`
- Swap the emoji or add a name for a more personal touch
